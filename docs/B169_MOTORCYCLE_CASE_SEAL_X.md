# b169 – Motorcycle case-specific seal x templates

b169 is a docs/handover sync for the separated Physical Lab work. The Card code is unchanged.

## Reason

b168 used one global fixed motorcycle seal x-template for all Kraftrad cases. Visual comparison against the four Anlage-4 Kraftrad reference layouts showed that this was wrong:

- normal: no meaningful improvement
- H/E: worse
- season: seal positions not good
- season + H/E: seal positions not good

## Lab-only change

The standalone Lab now uses case-specific motorcycle seal x handling:

- normal without season: wider 20 mm visible gap between HU and authority seal
- H/E without season: wider 20 mm visible gap and a 5 mm left correction
- season: compact b167 seasonal placement retained
- season + H/E: compact b167 seasonal placement retained

The season vertical template remains unchanged: the 3.25 mm separator is centered at y=100 mm; the upper month field is y=73.375–93.375 mm and the lower field is y=106.625–126.625 mm.

## Card status

No Card renderer integration in b169. Full/Card is only updated so the handover and docs stay current.
