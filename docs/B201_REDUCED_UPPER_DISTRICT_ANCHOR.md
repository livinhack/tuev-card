# b201 – Reduced upper district anchor

b201 documents the separate Physical Lab fix for the upper district position in Reduced Standard vertical-seal layouts.

The Card code is unchanged. The separate Lab ZIP is authoritative.

Fixed behavior:

- `W QU11` remains vertical and `240 mm`, but upper `W` no longer drifts right to the seal axis.
- `WI QU11` remains vertical and `240 mm`, with the upper text centered in the virtual three-letter district zone.
- `W QU111` still uses the upper side-by-side seal row.
- H/E or season still force the upper side-by-side seal row.
