# b177 – Reduced short top row softening

The Lab-only reduced two-line standard renderer keeps b172 discarded and builds on b175/b176. b176 showed that short top rows such as `WI` were still too far right. b177 keeps the same physical template but reserves full 31-mm top slots and uses the maximum `***` corridor of 20 mm before the top HU seal.

No Card code was changed. The separately delivered Lab ZIP is authoritative.
