# b178 – Reduced short top row slot-fill correction

The standalone Physical Lab fixes the reduced two-line standard template for short upper district rows. b176/b177 still treated the last written district letter too much like the third top slot. b178 keeps the confirmed reduced standard basis and changes only the short-top-row placement logic.

## Rule

For reduced two-line standard plates with fewer than three district letters in the top row:

- existing letters fill the 31-mm top slots from slot 1 toward slot 3,
- missing trailing slots are virtual placeholders,
- those placeholders do not pull the visible text rightward,
- the lower row and the common seal axis still determine the usable plate width,
- H/E, season and green reduced variants remain disabled.
