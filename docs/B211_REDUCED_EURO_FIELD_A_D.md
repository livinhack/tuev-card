# b211 – Reduced Euro-field star diameter and D-band centering

b211 updates only the standalone Physical Lab Euro-field component geometry.

## Lab change

- Reduced two-line Euro field keeps `35 × 56 mm` and the `5 / 22.5 / 8 / 15 / 5.5 mm` raster.
- EU star wreath now uses `a = 22.5 mm` through star centre points.
- Star size is `a / 6 = 3.75 mm`.
- Reduced country mark `D` keeps `15 mm` height and is centered in the 15-mm D band.

## Full/Card status

No Card renderer code was changed. The separate Lab ZIP remains authoritative.
`tools/plate-physical-lab/` in the Full ZIP is intentionally not synchronised / remains frozen unless explicitly stated otherwise.
