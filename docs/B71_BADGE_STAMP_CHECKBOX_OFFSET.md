# b74 - Badge stamp checkbox offset

This is a very small visual tuning release based on b70.

## Changed

- In the compact badge stamp variant (`show_badge: true` in tight multi-column layouts), the checkbox/hook field in the green HU stamp is shifted slightly to the right.
- The stamp frame, text sizing, animation timing, service-call behavior, and `show_badge: false` stamp remain unchanged.

## Reason

The b70 frame/text tuning looked good, but the checkbox sat a little too far left inside the green stamp.
