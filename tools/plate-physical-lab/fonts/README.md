Optionaler Fontordner für das Physical Lab.

- GL-Nummernschild-Mtl.ttf
- GL-Nummernschild-Eng.ttf

Für das Länderkennzeichen D kann zusätzlich diese Datei hier abgelegt werden:

- din1451alt.ttf

Alternativ kann `din1451alt.ttf` im Projekt-Root unter `fonts/` liegen.

Die Fontdateien sind nicht Teil der Chat-ZIPs.
